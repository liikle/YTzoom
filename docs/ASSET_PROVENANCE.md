# Asset provenance

## Bundled visual assets

- `sponsorblock_shield_template@3x.png` — original YTzoom project artwork supplied by the project owner.

All other settings and interface icons are requested from SF Symbols at runtime and are not redistributed as image files.

## Project resources

The localization files and bundle metadata are maintained as part of YTzoom. YouTube artwork, logos and thumbnails displayed by features are loaded from YouTube or from the user's own downloaded media and are not shipped in this repository.
